1. Introdução e Objetivo do Documento

A Portabilidade é uma característica fundamental de qualidade de software definida pela norma internacional ISO/IEC 25010, representando a capacidade de um produto ser transferido com eficácia de um ambiente para outro mantendo sua integridade operacional e nível de desempenho.

No contexto do LucroImpresso, a portabilidade atende a dois requisitos fundamentais: atender a diversidade de estações de trabalho de makers e pequenas oficinas (estações Windows, notebooks Linux, dispositivos móveis na bancada) e cumprir a diretriz de Custo R$ 0,00 (RNF008), garantindo que o software funcione sem a necessidade de adquirir licenças proprietárias de servidores ou runtimes pagos.

2. Enquadramento Normativo (ISO/IEC 25010)

1. Adaptabilidade (Adaptability)

Capacidade de executar em diferentes sistemas operacionais (Windows, Linux, macOS), processadores (x64, ARM64) e fatores de forma (Mobile, Tablet, Desktop) sem alteração de código.

2. Instalabilidade (Installability)

Facilidade de instalação e implantação através do runtime .NET 9, servidor embutido Kestrel ou orquestração em 1 comando com Docker Compose.

3. Substituibilidade (Replaceability)

Capacidade de substituir instâncias de banco de dados (MariaDB local, MariaDB em Docker, instâncias em nuvem) através do mapeamento agnóstico do Entity Framework Core 9.

4. Coexistência (Co-existence)

Capacidade de operar em perfeita harmonia com softwares fatiadores (UltiMaker Cura, PrusaSlicer, Bambu Studio) e repositórios 3D externos (Thingiverse, Printables).

5. Portabilidade de Banco de Dados e Criptografia

Padronização Universal de Datas em UTC: Todas as entidades do domínio (Orçamentos, Materiais, Máquinas, Clientes, Usuários e Histórico Financeiro) são gravadas utilizando fuso horário universal (DateTimeKind.Utc), assegurando que servidores hospedados em qualquer região geográfica ou contêiner preservem a integridade cronológica dos dados.

O acesso a dados é gerenciado pelo Entity Framework Core 9 utilizando o provedor Pomelo (MariaDB). O sistema suporta nativamente MariaDB 10.5+ (LTS recomendado: MariaDB 10.11) e serviços em nuvem gerenciados (AWS RDS, Google Cloud SQL, Railway).

6. Implantação Universal via Docker Compose (1 Clique)

Para viabilizar a portabilidade instantânea em qualquer ambiente sem necessidade de instalar manualmente runtimes ou bancos de dados locais, o projeto disponibiliza os arquivos Dockerfile e docker-compose.yml na raiz: 

# Credenciais do banco: copiar o modelo e ajustar o arquivo .env
cp .env.example .env

# Inicialização em contêiner em qualquer sistema operacional
docker compose up -d

# Verificação do status dos serviços
docker compose ps
