1. Visão Geral e Arquitetura da Rastreabilidade

A presente Matriz de Rastreabilidade de Requisitos (RTM) foi desenvolvida para assegurar a consistência bidirecional (Forward and Backward Traceability) entre os requisitos do sistema e o produto final de software. Cada funcionalidade possui rastreabilidade total: desde a necessidade elicitada junto ao ecossistema maker até a regra de negócio, caso de uso UML, pacote da EAP, entidade de dados, classe de repositório C#, tela do Blazor Server e caso de teste automatizado em xUnit.
